PitWall - F1 telemetry website (prototype)

Open index.html in any web browser (double-click it). No installation needed.
An internet connection is only needed for the Titillium Web font; everything else is inside the file.

What is included:
- Home, Schedule (season -> calendar -> race weekend), race pages with track map, telemetry, replay and radio panel, and a Live tab showing the next race.
- Real circuit outlines for Austin, Monza, Silverstone, Spa, Suzuka, Monaco, Interlagos, Yas Marina, Melbourne and Bahrain.

Not real yet: telemetry values, driver results and team radio are simulated demo data.
Circuit outlines come from the open f1-circuits dataset (MIT licence).
